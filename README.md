# Vnukovo School System

Рабочий веб-прототип внутренней школьной системы.

Сейчас используются только демонстрационные данные. Реальные персональные данные нельзя хранить в этом статическом прототипе или в GitHub.

## Структура
- `index.html` — интерфейс
- `src/styles.css` — стили
- `src/app.js` — логика и тестовые данные
- `docs/requirements.md` — зафиксированные правила системы
- `CHANGELOG.md` — история изменений

## Важно
Следующие изменения делаются только поверх этой версии с сохранением требований и истории.
