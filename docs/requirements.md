# Зафиксированные требования

## Роли
- Администратор: вся школа, назначения, хаус-мастера, классные руководители, прямые операции.
- Старший тьютор: всё в рамках своего звена; оперативные показатели только своего звена.
- Тьютор: только назначенные ему дети; прямые операции своим; запросы по чужим; получает запросы только по своим детям.
- Хаус-мастер: дополнительное назначение тьютора; отдельная вкладка VISION / IMPERIUM / SAPIENTIAE; ученики обоих звеньев.
- Классный руководитель: только назначенный класс и баллы; только предложения на начисление/списание без количества.
- Учитель-предметник: только две кнопки — предложить начисление / предложить списание; другой информации нет.

## Баллы
- Учебный год интерфейса: 2026/27.
- Выбор по месяцу: сентябрь–декабрь 2026, январь–май 2027.
- Июнь, июль, август исключены.
- В марте уточняется III или IV четверть.
- Разрешённым ролям можно редактировать уже созданную операцию.
- История ученика группируется по четвертям и месяцам.

## Нарушения
- Место: прогулка / перемена / раздевалка / урок / ресторан.
- Причина — свободный текст.
- Для прямой операции указывается количество списываемых баллов.
- Причина сопоставляется с Положением по смыслу и предлагает подходящий пункт, но решение принимает сотрудник.

## Ученики
- Тьюторов назначают классом или по одному ученику.
- Классному руководителю администратор назначает класс.
- Доступным сотрудникам разрешено назначать хаус своим детям.
- Поиск по ФИО; при совпадении уточнение по классу и хаусу.
- Общий поиск для тьюторов, старших тьюторов и администрации показывает ФИО, класс, хаус, родителей и телефоны.

## Общие рейтинги
- Общий рейтинг хаусов и Топ-15 + 3 — общешкольные.
- Администратор может скрыть Топ-15 для остальных сотрудников.
- Администратор может открыть/закрыть внесение баллов.
